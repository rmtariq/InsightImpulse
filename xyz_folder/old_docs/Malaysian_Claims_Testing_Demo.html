How to Use:

  1. Click any claim to copy it to clipboard
  2. Open InsightPulse at http://localhost:8000
  3. Paste the claim in the query field
  4. Select recommended platforms (shown as tags)
  5. Choose analysis type (shown in green badge)
  6. Run analysis and see rich interactive sentiment timeline!
