# Action Playbook — PRN N9

## Prinsip
Setiap tindakan mesti menjawab:

- Apa perlu dibuat?
- Kenapa tindakan ini dicadangkan?
- Siapa owner?
- Bila perlu siap?
- Apa bukti dan ukuran impak?

## Priority
- P1 Segera: perlu tindakan hari ini, biasanya seat kritikal, cula tiada update, atau isu berisiko.
- P2 Perhatian: perlu follow-up dalam 24-48 jam.
- P3 Pantau: tindakan berkala atau peluang amplifikasi.

## Kategori
- Lapangan: door-to-door, walkabout, ziarah, spot check PDM.
- Digital: seed post, crawl, post klarifikasi, video pendek.
- Rapid Response: semakan fakta, talking points, jurucakap.
- Program: ceramah kelompok, dialog komuniti, program belia.
- Koordinasi: briefing jentera, telekonferens ketua PDM.
- GOTV: reminder, volunteer mobilization, PACA readiness.

## Trigger-to-Action Examples
- Cula 24j tiada untuk kerusi sasaran: hantar ketua PDM sahkan data dan lawatan minimum 20 rumah.
- Isu digital naik 24j: sediakan post klarifikasi dan monitor selepas 12-24 jam.
- Engagement tinggi tetapi cula lemah: jalankan pulse digital + lawatan PDM di lokaliti sama.
- Program dibuat tetapi impak lemah: follow-up peserta dan masukkan cula dalam 24 jam.
