G. SELEPAS SETIAP CRAWL — LANGKAH WAJIB (COPY-PASTE)
================================================================================

1) Tunggu task siap di http://localhost:8001 (status: completed)

2) Gabung semua Combined_* hari itu → master baru:
   cd /Users/rmtariq/Documents/InsightPulse
   # Ganti YYYYMMDD dengan tarikh crawl
   NEImpulse/bin/python3 - <<'PY'
   import pandas as pd
   from pathlib import Path
   from datetime import datetime, timezone, timedelta
   ROOT = Path(".")
   MYT = timezone(timedelta(hours=8))
   TS = datetime.now(MYT).strftime("%Y%m%d")
   # Senaraikan fail Combined hari ini (social + news)
   files = sorted((ROOT/"data/combined").glob(f"Combined_*_{TS}_*.csv"))
   # ATAU gabung dengan master lama + fail baru
   prev = ROOT/"data/combined/PRN_Johor_N9_master_20260621.csv"
   parts = [pd.read_csv(prev, low_memory=False)] if prev.exists() else []
   parts += [pd.read_csv(f, low_memory=False) for f in files]
   df = pd.concat(parts, ignore_index=True)
   df["_key"] = df["Platform"].astype(str)+"_"+df["ID"].astype(str)
   df = df.drop_duplicates(subset=["_key"], keep="last").drop(columns=["_key"])
   out = ROOT/f"data/combined/PRN_Johor_N9_master_{TS}.csv"
   df.to_csv(out, index=False, encoding="utf-8")
   print(f"✅ {out} ({len(df):,} rows)")
   PY

3) Wire ke war room + rebuild:
   TS=$(date +%Y%m%d_%H%M%S)
