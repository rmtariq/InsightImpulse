# InsightImpulse: Marketing Intelligence & Social Listening Platform

## 1. Overview

**InsightImpulse** is an AI-powered social media intelligence and marketing analytics platform designed to help organizations, agencies, SMEs, brands, and public-sector teams understand what people are saying online, why it matters, and what actions should be taken next.

It collects real-time data from multiple digital platforms, analyzes public sentiment, detects emotions, identifies risks and opportunities, and generates professional reports for decision makers.

---

## 2. Marketing Purpose

InsightImpulse is built to support modern marketing, brand monitoring, reputation management, campaign tracking, and public communication strategy.

The platform helps users answer key marketing questions:

- What is the public sentiment toward our brand, campaign, issue, product, or organization?
- Which platforms are driving the most engagement?
- What topics, keywords, and narratives are trending?
- Are people reacting positively, negatively, or neutrally?
- Which posts or comments require urgent attention?
- What content should be amplified?
- What communication strategy should be used next?

## 7. AI and Analytics Tools

InsightImpulse uses a combination of crawling tools, AI models, and analytics engines.

### Data Collection Tools

- Apify actors for social media crawling
- SerpAPI for search and news discovery where applicable
- Custom crawler adapters
- Platform-specific scraping strategies
- SQLite-based crawl cache for reducing duplicate data collection

### AI / NLP Tools

- Hugging Face Transformers
- Custom Malay sentiment model
- Multilingual emotion classifier
- Language detection logic
- Token-safe text truncation for long social media content
- Sentiment score normalization
- Emotion classification

### Reporting Tools

- FastAPI backend
- Chart.js interactive dashboards
- Pandas for data processing
- CSV exports
- PowerPoint report generation
- DOCX executive documents
- Static HTML dashboard reports

### Optional OpenAI API Usage

OpenAI API can be used to enhance:

- Executive summaries
- Strategic recommendations
- Communication plans
- Crisis response guidance
- Marketing campaign interpretation
- Board-level narrative reports

However, core sentiment labels should remain based on the platform’s analyzed data models to maintain consistency and traceability.
