DOSM MyCensus 2020 — Johor and Negeri Sembilan

Package contains state, district and DUN summaries plus filtered raw CSVs.
2020 values are census data. State/district values are rounded to 0.1 thousand; DUN values to 0.001 thousand.
Exact state totals: Johor 4,009,670; Negeri Sembilan 1,199,974.
Use demographic data as context, not as a direct indicator of political support.

State source: https://storage.dosm.gov.my/population/population_state.csv
District source: https://storage.dosm.gov.my/population/population_district.csv
DUN source: https://storage.dosm.gov.my/population/population_dun.csv
