## 📈 RESEARCH METHODOLOGY

### Data Collection
- **Time Period**: 30-day rolling window (May 2026)
- **Platforms**: 10 (Facebook to Lazada)
- **Languages**: Malay, English, Chinese, Mixed
- **Total Records**: 3,572 (2,925 Organization A + 647 Organization B)
- **Organizations**: Anonymized (waste management + transportation)
- **Geographic Areas**: Anonymized (Area X, Y, Z, W, V)

### Analytics Framework (InsightPulse)
1. **Multi-platform Data Collection**: Third-party API aggregators + ethical web crawling
2. **Sentiment Models**: 4 transformer-based NLP models (Malay, English, Chinese, Multilingual)
3. **Theme Classification**: Keyword + context analysis (9 complaint themes for Org A)
4. **Geographic Extraction**: Named entity recognition + pattern matching (anonymized)
5. **Engagement Metrics**: Total engagement calculation + severity scoring

### Validation
- **Human Coders**: Random sample (n=100)
- **Inter-coder Reliability**: Cohen's κ = 0.82
- **Theme Precision**: 78% (Organization A), 81% (Organization B)
