## ❓ FAQ

### **Q: Where is the 8,351 raw file?**
A: It wasn't saved as a separate file. The count was tracked during the initial combination step in memory. The deduplication step ran immediately after, producing the 5,906 clean file.

### **Q: Can I recreate the 8,351 file?**
A: Only if you have the original 6 separate query CSV files. Otherwise, the clean 5,906 is your starting point.

### **Q: Which file should I use for analysis?**
A: Use `pas_bersatu_split_posts_corrected.csv` (5,906 records) - it has both deduplication and political context corrections.

### **Q: How was engagement calculated to 136M?**
A: Sum of `total_engagement` column from the 5,906 clean records:
```python
df['total_engagement'].sum() = 136,349,751
```

### **Q: What happened to the 2,445 removed records? (8,351 - 5,906)**
A: Removed as duplicates:
- Cross-platform reposts
- Identical content on multiple platforms
- Same post shared multiple times
- But their engagement was preserved in the main post record
