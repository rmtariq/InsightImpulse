# Rapid Response Playbook — PRN N9

## Bila Digunakan
Gunakan Rapid Response apabila:

- Sentimen negatif naik mendadak.
- Isu salah fakta mula viral.
- Isu komuniti sensitif meningkat.
- Lawan berjaya membentuk naratif yang boleh menjejaskan seat sasaran.

## Format Minimum
Setiap isu rapid response perlu ada:

- Isu semasa.
- Tahap risiko.
- Sumber/bukti.
- Cadangan respons awal.
- Talking points ringkas.
- Owner.
- Due time.
- Cara monitor impak.

## Cadangan Tindakan
- Post klarifikasi BM.
- Video pendek TikTok/Reels.
- Tele-briefing dalaman untuk ketua DUN/PDM.
- Semakan fakta.
- Agihan jurucakap.
- Monitor impak selepas respons.

## Prinsip Copy
- Ringkas.
- Tidak defensif berlebihan.
- Ada fakta.
- Ada CTA jelas.
- Bahasa komuniti digunakan hanya apabila perlu dan sudah disemak.
