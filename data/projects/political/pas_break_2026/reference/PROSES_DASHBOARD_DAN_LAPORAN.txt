LANGKAH 4 — JANA LAPORAN TINDAKAN (PDF + DOCX per negeri)
================================================================================

  cd /Users/rmtariq/Documents/InsightPulse

  # Semua 3 negeri
  ./scripts/run_prn_chinese_manual.sh reports

  ATAU:
  n9_chinese_narrative_dashboard/.venv/bin/python3 \
    scripts/generate_prn_chinese_narrative_reports.py

  # Satu negeri sahaja
  python3 scripts/generate_prn_chinese_narrative_reports.py --negeri johor
  python3 scripts/generate_prn_chinese_narrative_reports.py --negeri melaka
  python3 scripts/generate_prn_chinese_narrative_reports.py --negeri n9

  # Rebuild dataset + laporan sekali gus
  python3 scripts/generate_prn_chinese_narrative_reports.py --rebuild-data

  OUTPUT (2 jenis × 3 negeri):
    data/projects/political/pas_break_2026/reports/chinese_narrative/
      PRN_Executive_{negeri}_YYYYMMDD_HHMMSS.pdf/.docx   ← 4 ms + cover
      PRN_Lampiran_{negeri}_YYYYMMDD_HHMMSS.pdf/.docx    ← analitik penuh
      README_LAPORAN.md

  KANDUNGAN LAPORAN EKSEKUTIF (maks. 4 ms + cover):
  ────────────────────────────────────────────────────
  • Cover — tajuk, negeri, tempoh, versi, UNTUK KEGUNAAN DALAMAN
  • Ms 1: Ringkasan Eksekutif (8 KPI, 2 carta, 3 bahagian bullet)
  • Ms 2: Lima Isu Utama (Belum Diklasifikasikan dikecualikan)
  • Ms 3: Papan Tindakan (maks. 6 tindakan dengan KPI)
  • Ms 4: Risiko, Pengesahan, Pelan Masa, Sign-off

  LAMPIRAN: petikan penuh, jadual, metodologi, brief

  Opsyen:
    python3 scripts/generate_prn_chinese_narrative_reports.py --executive-only
    python3 scripts/generate_prn_chinese_narrative_reports.py --appendix-only
