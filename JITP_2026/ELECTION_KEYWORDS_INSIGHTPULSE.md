### 1. Single Keyword Search
```
Query: "Pilihan Raya Umum"
Platforms: Facebook, X, Instagram, News
Dataset Size: 500
```

### 2. Multiple Keywords (OR)
```
Query: "PRU16 OR Pilihan Raya OR Malaysian Election"
Platforms: All 10 platforms
Dataset Size: 1000
```

### 3. Candidate Monitoring
```
Query: "[Candidate Name]"
Platforms: Facebook, X, TikTok, YouTube
Dataset Size: 300
Time: Real-time monitoring
```

### 4. Issue-Based Monitoring
```
Query: "Kos Sara Hidup OR Inflasi OR Cost of Living"
Platforms: Facebook, News, Lowyat
Dataset Size: 500
```

### 5. Sentiment Tracking
```
Query: "[Party Name] AND (sokong OR tolak OR kecewa OR gembira)"
Platforms: All social media
Dataset Size: 1000
```

### 6. Crisis Detection
```
Query: "Penipuan OR Fraud OR Phantom Voters OR Fitnah"
Platforms: X, Facebook, News
Dataset Size: 500
Alert: Enable real-time notifications
```
